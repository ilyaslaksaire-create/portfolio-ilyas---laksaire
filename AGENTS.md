## Design

- Thème sombre vert/bleu.
- Graphismes informatiques visibles.
- Grille de fond, halos lumineux, topologie réseau, serveurs et cartes modernes.
- Navigation fixe et section active soulignée.
- Design responsive sur ordinateur, tablette et téléphone.
- Conserver un contraste lisible.
- Ne pas transformer le site en fond blanc.

## Technique

- HTML, CSS et JavaScript sans framework.
- Le CSS et le JavaScript doivent rester intégrés dans `index.html` afin que le fichier fonctionne seul.
- Ne pas ajouter de dépendance nécessitant une installation.
- Préserver les attributs d’accessibilité.
- Respecter `prefers-reduced-motion`.
