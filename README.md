# Portfolio moderne d’Ilyas Laksaire

Cette version est un site **one-page autonome** : le CSS et le JavaScript sont directement intégrés dans `index.html`.

Cela évite le problème du fond blanc ou des styles qui ne se chargent pas lorsque le fichier HTML est ouvert directement.

## Navigation

Quatre onglets en haut à droite :

- Accueil
- École
- Entreprise
- Contact

## Ouvrir le site

Double-clique sur `index.html`, ou ouvre-le avec Live Server dans Visual Studio Code.

## Utiliser avec Codex

Le fichier `AGENTS.md` précise les règles du projet.

Exemples de demandes à donner à Codex :

```text
Modifie les missions chez MyGenAI sans changer le design.
```

```text
Ajoute ma photo dans la section Accueil en conservant le graphisme réseau à droite.
```

```text
Remplace l’adresse e-mail d’exemple dans le formulaire et le lien mailto.
```
